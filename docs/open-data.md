# Реальные данные для демо

Администратор → **09 Реальные данные**. Две независимые вкладки:

- **Kelmarsh**: 177 исходных записей Stop / Forced outage по шести турбинам за 2016 год. Фильтры оборудования и дат, месячные часы остановок, история повторения кода, исходные записи и экспорт CSV.
- **MaintIE**: 80 коротких английских текстов с экспертной разметкой. Кнопка разбора запускает независимые правила или настроенный ИИ. Эталон виден отдельно; сравниваются точные границы токенов и пять верхних классов. Это не результат обучения модели и не оценка на всём корпусе.

Выборки входят в репозиторий и работают без загрузок при открытии сайта. Без внешнего ИИ доступны все расчёты и разбор по правилам. Источники не записываются в текущие заявки цеха, не запускают email-уведомления, не используют его демонстрационные тарифы или прогнозы.

## Kelmarsh

Plumley, Charlie; Takeuchi, Roberta. **Kelmarsh wind farm data**, v4, Cubico Sustainable Investments Ltd, 2025. DOI: [10.5281/zenodo.16807551](https://doi.org/10.5281/zenodo.16807551).

Данные опубликованы под [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Лицензия данных сохраняется; MIT-лицензия приложения их не заменяет.

Из архива `Kelmarsh_SCADA_2016_3082.zip` взяты только шесть файлов `Status_Kelmarsh_*`. Оставлены все полные строки с `Status=Stop`, `IEC category=Forced outage` и положительной длительностью. Пять неполных строк исключены с указанием файла и номера в манифесте. Даты не сдвигались, случайной выборки событий нет. Статус источника может описывать ручную, защитную или внешнюю остановку; это не доказательство механической поломки или замены детали.

Преобразования FixList: CSV → JSON, стабильные ID, время UTC, длительность в секундах (проверяется по исходной длительности), русские подписи для интерфейса. Английские сообщения и исходные поля сохранены.

Часы считаются объединением пересекающихся/соприкасающихся интервалов **отдельно по каждой турбине**. На границах фильтра даты интервалы обрезаются. Месячные значения распределяют интервал между соответствующими месяцами. Сумма часов разных агрегатов — агрегато-часы, а не длительность остановки всего парка. Количество записей и количество объединённых периодов показаны раздельно.

Для истории повторений используется пара «турбина × исходный код». Интервалы рассчитываются между началами объединённых периодов этой пары, а не между произвольными сообщениями. График повторений и карточка сохраняют полную длительность исходной записи, в том числе при пересечении границы фильтра.

Цен ремонта, запчастей, назначенных исполнителей и подтверждённой экономии в источнике нет. Финансовые результаты, причины отказа, рекомендации и даты следующих поломок не придумываются.

CSV-экспорт включает ссылку на датасет, авторов, лицензию и описание преобразований вместе с исходными сообщениями и номерами строк.

## MaintIE

Bikaun, Tyler K.; French, Tim; Stewart, Michael; Liu, Wei; Hodkiewicz, Melinda. **MaintIE: Maintenance Information Extraction**, 2024. [Репозиторий](https://github.com/nlp-tlp/maintie).

Авторы распространяют корпус, схему и модели под MIT. Оригинальный файл лицензии сохранён как [MaintIE_LICENSE.md](../data/external/MaintIE_LICENSE.md), включая опубликованную авторами строку copyright без её изменения.

Взяты 80 записей `gold_release.json`: тематический фильтр промышленных узлов, минимум 3 токена и 2 сущности, затем детерминированная выборка с seed=42. Это целевая демовыборка, не случайная репрезентативная оценка всего корпуса. Точный commit, контрольные суммы и нулевые индексы исходных записей сохранены. Тексты, токены, полные типы и связи не менялись; добавлены только ID и source_index.

Идентификаторы, числа и даты уже обезличены авторами. Отсутствующие даты, простой и стоимость не заполняются нулями. Записи MaintIE не приписываются оборудованию Kelmarsh.

При разборе алгоритм получает **только токены**, а не эталонные сущности или связи. Результат ИИ проверяется по допустимым классам, границам токенов и отсутствию маскированных значений в извлечённых фрагментах. При недоступности ИИ включаются явно обозначенные правила. Сравнение с эталоном выполняется после извлечения, отдельно для выбранного примера.

## Обновление выборок

Обычно обновление не требуется. Явный запуск с сетью:

```sh
python scripts/fetch_open_data.py
```

Скрипт читает только необходимые ZIP-члены через HTTP Range и проверяет их CRC. Он не скачивает гигабайты SCADA и не запускается автоматически. При повторном запуске версия MaintIE обновляется до main на момент загрузки и фиксируется в новом манифесте; изменения выборки нужно проверить перед принятием.

`data/external/manifest.json` содержит авторов, ссылки, лицензии, отбор, преобразования, контрольные суммы файлов и происхождение. Файлы данных проверяются по SHA-256 при первом чтении приложением.

## Маршрут показа

1. Открыть реальные данные: шесть агрегатов и архивный период.
2. Показать сводку, выбрать турбину и повторяющийся сигнал.
3. Открыть событие перегрузки масляного насоса редуктора: 26.05.2016, 9:27:40; раскрыть оригинал.
4. Переключиться на MaintIE, разобрать запись и сравнить результат с эталоном.
5. При вопросах открыть вкладку источников. Измеренные результаты конкретных ремонтов и предотвращённые поломки в этом демо не заявляются.
