# Смена.AI — визуальный прототип

Изолированный Streamlit-интерфейс. Не изменяет backend, не вызывает LLM, не пишет в SQLite. Демо-отметки и новые записи хранятся только в session_state и исчезают после завершения сеанса.

## Запуск

```sh
python -m pip install -r requirements-ui.txt
python -m streamlit run ui_preview.py
```

## Передача разработчику

- `ui/theme.css` — палитра, типографика, карточки, адаптивные стили.
- `ui/theme.py` — `apply_theme()`, `heading()` и `card()`. Текст HTML-компонентов экранируется.
- `ui_preview.py` — четыре экрана и UI-состояния. Можно переносить блоки в `app.py` постепенно, сохраняя существующие вызовы backend.
- Подключить `extract` к кнопке разбора; выводить реальные поля/needs_clarification вместо готового примера.
- Подтверждение записи связать с db; session_state.saved заменить чтением истории.
- Карточки аномалий, источники и показатели заменить результатом analytics.
- Меры и расчёты заменить результатами advisor/analytics. Сохранение внедрения связать с applied_measures.
- После подключения удалить ограничение на точный текст примера и заменить подписи о визуальном прототипе на фактический режим работы. ДЕМО сохранять для демонстрационных данных.
