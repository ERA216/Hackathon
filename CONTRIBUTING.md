# Как участвовать

1. Создайте ветку от `main`: `git checkout -b feature/название`.
2. Запустите тесты перед коммитом: `python tests/test_backend.py`.
3. Не коммитьте `.env`, `smena.db`, `.session_secret` и `__pycache__` — они в `.gitignore`.
4. Интерфейс вызывает только функции из `backend/service.py`; новую логику добавляйте в `backend/`.
5. Ответы ИИ всегда проверяйте кодом: справочники, исходный текст, расчёты.
6. Откройте pull request с коротким описанием, что и зачем изменено.
